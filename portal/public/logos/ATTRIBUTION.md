# Logo attribution

Official vendor artwork used **nominatively** on the `/docs` surface to
label wire-format compatibility ("OpenAI-compatible",
"Anthropic-compatible"). Files are self-hosted under
`portal/public/logos/` — no hotlinking, no CDN dependency.

| File | Source | License / rights |
|---|---|---|
| `openai-blossom.svg` | [OpenAI logo 2025 (symbol)](https://commons.wikimedia.org/wiki/File:OpenAI_logo_2025_(symbol).svg), via Wikimedia Commons | Public domain (`PD-textlogo`); **trademark of OpenAI**. Used to label the OpenAI-compatible endpoint. |
| `anthropic.svg` | [Anthropic logo](https://commons.wikimedia.org/wiki/File:Anthropic_logo.svg), via Wikimedia Commons | Public domain (`PD-textlogo`); **trademark of Anthropic**. Used to label the Anthropic-compatible endpoint. |
| `claude.svg` | [Claude AI logo](https://commons.wikimedia.org/wiki/File:Claude_AI_logo.svg), via Wikimedia Commons | Public domain (`PD-textlogo`); **trademark of Anthropic**. Used to label the Claude Code integration. |

Codex has no separate official logo — the CLI ships under the OpenAI
brand, so the Codex card reuses the OpenAI blossom with a CLI caption.
